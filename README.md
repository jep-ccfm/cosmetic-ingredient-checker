# 화장품 성분 오탈자 검사기 (웹앱)

패키지 단상자 **PDF**에서 전성분을 AI로 판독하고, 작성 문안 **엑셀** 셀과 대조하여
오탈자·불일치·순서 문제를 찾아냅니다. 기존 데스크톱(Tkinter) 앱을 Vercel 배포용 웹앱으로 전환한 버전입니다.

## 구조

```
브라우저 (정적)                          Vercel 서버리스
─────────────────                        ─────────────────
index.html / app.js / styles.css         api/extract.js
  · pdf.js  : PDF → 이미지                   · Claude 비전 호출
  · SheetJS : 엑셀 셀 읽기                    · 회사 API 키는 여기에만 보관
  · 비교 로직(오탈자/불일치/순서)      ─►    (브라우저에 키 노출 없음)
```

- 전성분 텍스트 비교는 전부 브라우저에서 처리됩니다.
- PDF 이미지 판독 시에만 이미지가 서버리스 함수를 거쳐 Claude로 전송됩니다.

## 배포 (Vercel)

1. 이 저장소를 Vercel에서 Import 합니다. (프레임워크: **Other** / 빌드 설정 불필요)
2. **Settings → Environment Variables** 에 회사 키를 추가합니다:
   - `ANTHROPIC_API_KEY` = `sk-ant-...`
   - (선택) `MODEL` = `claude-sonnet-5` — 비용 절감용 (미설정 시 `claude-opus-4-8`)
3. Deploy. 정적 파일은 루트에서, `/api/extract`는 서버리스 함수로 자동 서빙됩니다.

## 로컬 실행

```bash
npm i -g vercel
vercel dev
```

`vercel dev`는 정적 파일과 `/api` 함수를 함께 띄웁니다. 로컬에서는 `.env`에
`ANTHROPIC_API_KEY`를 넣거나 `vercel env pull` 로 가져옵니다.

## 사용법

1. 단상자 **PDF** 선택
2. 문안 **엑셀** 선택 + 전성분이 들어있는 **시트명 / 셀 주소** 입력 (예: `Sheet1` / `A1`)
3. **분석 시작** → 결과 탭에서 오탈자·불일치·순서 확인

## 판정 로직

- **성분 파싱**: 콤마로 분리하되 `1,2-헥산디올` 같은 성분은 자동 복원
- **정규화**: 소문자 + 공백/제로폭문자 제거 후 비교
- **오탈자 의심**: 한쪽에만 있는 성분 간 문자 유사도 ≥ 70%
- **순서 검사**: 위치별로 성분을 비교해 순서/개수 불일치 검출
- **판독 정확도**: 오탈자 검사 특성상 판독 오류를 막기 위해 기본 모델은 `claude-opus-4-8`

## 참고

- Vercel Hobby 요청 본문 한도(약 4.5MB)로 인해 페이지 수가 매우 많은 PDF는
  이미지 해상도(`app.js`의 `MAX_EDGE`)나 페이지 분할 조정이 필요할 수 있습니다.
