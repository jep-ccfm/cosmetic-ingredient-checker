# 화장품 패키지 문안 검수기 (웹앱)

**기준 문안 PDF(정답)**와 **디자인 PDF(검수 대상)**를 AI로 대조해, 디자인의
오탈자·미기재·오기재를 찾아 **디자인 이미지 위에 형광펜으로 표시**합니다.
두 문서는 위치가 달라도 내용(문구) 기준으로 매칭하며, 회전·저해상도 이미지도 판독합니다.

## 구조

```
브라우저 (정적)                              Vercel 서버리스
─────────────────                            ─────────────────
index.html / app.js / styles.css             api/compare.js
  · pdf.js  : 두 PDF → 고해상도 이미지           · Claude 비전으로 두 문서 대조
  · 문제 위치에 하이라이트 오버레이       ─►      · 문제별 위치 좌표(정규화 box) 반환
  · 결과/텍스트 렌더                             · 회사 API 키는 서버에만 보관
```

- 판독·대조는 서버리스 함수(`/api/compare`)의 Claude 비전 호출로 수행됩니다.
- 회사 API 키(`ANTHROPIC_API_KEY`)는 서버 환경변수에만 있고 브라우저에 노출되지 않습니다.

## 검수 로직

- **기준 문안 = 무조건 정답.** 디자인에서 다음을 찾습니다:
  - **오탈자**: 같은 항목인데 철자/글자가 틀림
  - **미기재**: 문안엔 있는데 디자인에 빠짐
  - **오기재**: 숫자·용량·문구가 문안과 다르게 잘못 적힘
- **위치 표시**: 각 문제의 디자인 페이지 + 정규화 좌표(0~1)를 받아 이미지 위에 형광펜 박스로 표시(번호는 문제 목록과 연동). 좌표는 AI 추정치라 실제와 약간 다를 수 있습니다.
- **회전/화질**: 페이지 회전은 렌더러가 자동 보정, 콘텐츠 회전·저해상도는 비전 모델이 판독. 긴 변 2400px 고해상도로 전송.

## 배포 (Vercel)

1. 이 저장소를 Vercel에서 Import (프레임워크: **Other**, 빌드 설정 불필요)
2. **Settings → Environment Variables**:
   - `ANTHROPIC_API_KEY` = `sk-ant-...` (필수)
   - (선택) `MODEL` = `claude-sonnet-5` — 비용 절감 (미설정 시 `claude-opus-4-8`)
3. Deploy. 정적 파일은 루트, `/api/compare`는 서버리스 함수로 자동 서빙됩니다.

## 로컬 실행

```bash
npm i -g vercel
vercel dev
```

## 사용법

1. **① 기준 문안 PDF**(정답) 선택
2. **② 디자인 PDF**(검수 대상) 선택
3. **검수 시작** → [검수 결과] 탭에서 하이라이트 이미지 + 문제 목록 확인

## 참고

- Vercel Hobby 요청 본문 한도(약 4.5MB)로 인해 페이지가 매우 많은 PDF는
  이미지 해상도(`app.js`의 `MAX_EDGE`)나 페이지 분할 조정이 필요할 수 있습니다.
